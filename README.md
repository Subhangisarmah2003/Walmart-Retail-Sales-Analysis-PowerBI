#  Walmart Retail Sales Performance | Power BI Dashboard

### Transforming Retail Data into Meaningful Business Insights

## 📌 Project Overview

This project focuses on analyzing Walmart retail sales performance using Microsoft Power BI. It features an interactive dashboard designed to monitor sales trends, evaluate store performance, and understand department-wise sales distribution.

The dashboard provides a clear overview of key business metrics through KPI cards, interactive visualizations, and slicers, helping users explore sales performance across different years, stores, and departments.

##  Project Objectives

- Analyze overall retail sales performance.
- Track sales trends over time.
- Identify top-performing stores based on sales.
- Evaluate department-wise sales distribution.
- Monitor key performance indicators (KPIs).
- Enable interactive analysis using slicers and filters.
- Present business insights through effective data visualization.

##  Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- Interactive Slicers & Filters
- KPI Development

##  Dashboard Features

### 1. Sales Trend Over Time
- Visualizes sales performance across different dates.
- Helps identify fluctuations and significant sales peaks.
- Provides an overview of historical sales trends.

### 2. Top 10 Stores by Sales
- Compares store-level sales performance.
- Highlights leading stores based on sales contribution.
- Helps identify high-performing retail locations.

### 3. Total Sales by Department
- Displays sales distribution across departments.
- Helps compare department-level performance.
- Supports identification of major sales contributors.

### 4. Interactive Filters & Slicers

The dashboard includes interactive slicers for:

- **Year:** Filter sales performance by year.
- **Store:** Explore individual store performance.
- **Department:** Analyze specific department sales.
